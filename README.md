# Shroomate/homebrew-tap

```sh
brew trust shroomate/tap
brew install shroomate/tap/wheredns
```

Homebrew 7 and later only load formulae from third-party taps after they are
trusted. `brew untrust shroomate/tap` reverses it.

| Formula | Source |
|---|---|
| `wheredns` | [Shroomate/wheredns-cli](https://github.com/Shroomate/wheredns-cli) |
